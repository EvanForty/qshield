Your address is already public.

A Solana address is an ed25519 public key. It's on chain the first time anyone sends you something. Classical computers can't work backwards from it to your private key.

A large enough quantum computer running Shor's algorithm could. Because the chain keeps everything, those keys can be collected today and attacked later. Moving after that day is too late for any key that was already exposed.

Vaults that don't trust curves.

SOL in a QSHIELD vault sits at a program address with no elliptic-curve key behind it. It only moves with a one-time Winternitz signature, built from hash chains in your browser.

Why hashes

Shor's algorithm breaks the discrete-log problem behind ed25519. Hash functions don't have that structure. The best known quantum attack on them, Grover's search, only square-roots the work, so a 256-bit hash still leaves around 2¹²⁸ steps.

One key, one use

A Winternitz key is 67 secret values. Signing reveals a point partway along each value's hash chain. Anyone can finish the chains and check they land on your public key. Reusing a key leaks more of each chain, so every vault withdrawal rotates to a fresh one.
